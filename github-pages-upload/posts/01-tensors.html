让公式长出代码

从张量形状到一个完整训练循环

多模态训练 · 第 2 篇

张量形状是公式与程序之间的契约

在深度学习代码里，最先要读懂的往往是形状。设一批数据有 B 个样本，每个样本有 N 个位置，每个位置用 D 维向量表示，那么它的形状就是 [B, N, D]。

图像、文字和音频的原始形状不同，经过编码后却经常都成为这种序列表示。“都变成 token”不代表语义已经对齐，只是它们能进入类似的计算结构。

形状 含义 常见误区
[B, 3, H, W] 一批 RGB 图像 混淆通道和空间维度
[B, L] 一批文本 token 编号 把整数编号当作连续特征
[B, L, D] 每个 token 的向量 对错误的维度做归一化
[B, B] 批次内所有图文配对分数 误以为只计算了正确配对

从一行矩阵乘法开始

import torch

B, D = 4, 8
images = torch.randn(B, D)
texts = torch.randn(B, D)
scores = images @ texts.T
assert scores.shape == (B, B)

第 i 行、第 j 列，是第 i 张图与第 j 段文字的内积。这里并没有真实图像和文字；随机张量只用于理解运算。

矩阵乘法要求内侧维度相等。转置不会“改变样本含义”，而是改变我们怎样组合索引。养成习惯：写运算前先在纸上写出形状。

梯度是在计算图里传播的

设损失是参数的复合函数。自动微分利用链式法则计算导数，并把参数梯度存到 .grad。优化器随后读取这些梯度，更新参数。

w = torch.tensor(2.0, requires_grad=True)
loss = (3 * w - 1) ** 2
loss.backward()
print(w.grad)  # 30：2 × (3×2−1) × 3

注意：backward() 计算梯度，optimizer.step() 才更新参数。多次反向传播默认会累加梯度，所以常规每步训练需要清理旧梯度。

一个训练步骤要完成什么

# model、optimizer、inputs、targets 已提前创建
model.train()
optimizer.zero_grad(set_to_none=True)
predictions = model(inputs)
loss = loss_function(predictions, targets)
loss.backward()
optimizer.step()

评估通常使用 model.eval() 与 torch.no_grad()。前者改变 dropout 等层的行为，后者关闭梯度记录；它们不能互相替代。也要区分张量的数据类型与设备：浮点特征、整数标签，以及 CPU 和 GPU，需要符合各个运算的要求。

先让十几个样本学得会

完整数据训练失败时，很难确定原因。先固定十几个样本，关闭随机增强，用一个容量足够的小模型反复训练。若连这组样本都无法拟合，应优先检查标签、损失、梯度和参数更新。

小样本过拟合是实现的检查工具，不是泛化证明。通过后，仍要回到独立验证集，检查未见数据上的表现。

本篇练习

运行上面的标量梯度例子，先手算答案。再把 w 改成向量，分别观察 sum() 和 mean() 怎样影响梯度的尺度。
