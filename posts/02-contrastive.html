图片和文字，如何认出彼此

从一个配对矩阵理解 CLIP

多模态训练 · 第 3 篇

把配对问题变成分类问题

假设一个批次有四张图片，依次是猫、狗、自行车和船；同时有四条按相同顺序排列的描述。模型分别编码图像和文字，再计算所有十六种配对的相似度。

训练希望正确配对分数更高。对于第一张图片，任务就是从四条描述中选出第一条。对每张图片重复这个过程，再反过来让每条描述选择图片。

相似度矩阵与温度

设归一化后的图像向量是 v，文字向量是 t。两个单位向量的内积等于余弦相似度。除以正的温度参数 τ 后得到用于分类的分数。

sᵢⱼ = (vᵢᵀ tⱼ) / τ

归一化图文向量的内积，除以温度 τ。

温度越小，相同分数差异经过 softmax 后通常会产生更尖锐的分布。但不能简单说“温度越小越好”：梯度的大小和集中程度都会变化，错误配对也可能被放大。

写出单向损失

ℒᵢ→ₜ = −(1/B) ∑ᵢ log [ exp(sᵢᵢ) / ∑ⱼ exp(sᵢⱼ) ]

对每张图片，最大化正确文字在所有候选中的概率。

分子对应正确文字；分母包含批次中的所有候选文字。负对数使正确项的概率越高，损失越低。文字到图像的损失使用转置后的分数矩阵，最终取两者的平均。

下面是教学版本，温度固定，且假设每个样本只有一个配对正样本。

import torch
import torch.nn.functional as F

def contrastive_loss(image_features, text_features, temperature=0.07):
    if temperature <= 0:
        raise ValueError("temperature must be positive")
    image_features = F.normalize(image_features, dim=-1)
    text_features = F.normalize(text_features, dim=-1)
    logits = image_features @ text_features.T / temperature
    labels = torch.arange(logits.shape[0], device=logits.device)
    return (
        F.cross_entropy(logits, labels)
        + F.cross_entropy(logits.T, labels)
    ) / 2

cross_entropy 接收 logits，内部完成相应的归一化计算。不要先对它们做 softmax 再传入。归一化沿最后一个特征维度进行，而不是沿批次维度。

一个很有用的导数

对于某一行，设 softmax 概率是 p，正确标签是 y，则交叉熵对每个 logit 的导数为 p_j − 1[j=y]。正确项对应向上调整分数的方向，错误项对应向下调整的方向。真实参数同时影响很多分数，因此实际更新由所有路径共同决定。

这能帮助你理解为什么“难负样本”会提供明显梯度，也能解释为什么错误的负样本会造成冲突。

配对标签并不等于完整语义

一张猫的图片与另一条“猫在地毯上”的文字可能同样匹配，但它们没有出现在对角线上。简单损失仍会把它当成负样本。这是假负样本问题。

类似地，擅长识别“狗和球”不等于能分清“狗在球左边”和“球在狗左边”。全局对齐任务未必充分监督了关系、数量和位置。

记录训练前后在独立样本上的双向 Recall@1。在这里，每个查询只有一个指定配对，Recall@1 就是正确配对排在第一位的比例。再改变温度，比较损失与结果，不要只比较不同温度下损失的绝对值。

验收：解释 [B,B] 矩阵的每个元素、对角线标签和双向损失；能说明人工数据实验的能力边界。
